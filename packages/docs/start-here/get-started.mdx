<Note>
  These docs describe a **self-hosted-only fork**. OpenWork's hosted control
  plane — OpenWork Den, its organization model, the AI Gateway, and the MCP
  Gateway — has been removed from the repository. There is nothing to sign up
  for. Everything below runs on your machine or your own server.
</Note>

## What there is

## Get started in four steps

<Steps>
  <Step title="Install">
    Install the desktop app, or run `npm install -g openwork-server` and start
    the server yourself.
  </Step>
  <Step title="Pick a folder">
    OpenWork only works in folders you authorize.
  </Step>
  <Step title="Choose a model">
    [Sign in with ChatGPT](/start-here/connect-your-stack/sign-in-with-chatgpt), [add an API key](/start-here/connect-your-stack/add-anthropic-api-key), [run a local model](/start-here/connect-your-stack/use-local-models), or [point it at your own gateway](/start-here/connect-your-stack/add-a-custom-llm).
  </Step>
  <Step title="Run a task">
    Start with "Summarize this folder."
  </Step>
</Steps>

## Models are yours to choose

There is no bundled model catalog in this fork and no default inference
provider. You configure one:

<CardGroup cols={2}>
  <Card title="Bring your own key" icon="key" href="/start-here/connect-your-stack/add-anthropic-api-key">
    Anthropic, OpenAI, OpenRouter, or any OpenAI-compatible endpoint.
  </Card>
  <Card title="Run local models" icon="cpu" href="/start-here/connect-your-stack/use-local-models">
    Ollama, or any OpenAI-compatible server on your own hardware.
  </Card>
  <Card title="Use your own gateway" icon="route" href="/start-here/connect-your-stack/add-a-custom-llm">
    LiteLLM, Bifrost, or anything else — set the provider's base URL.
  </Card>
  <Card title="Sign in to ChatGPT" icon="sparkles" href="/start-here/connect-your-stack/sign-in-with-chatgpt">
    Or use Gemini and Vertex AI.
  </Card>
</CardGroup>
