This fork is **MIT licensed in full**. There is no open-core split, no
source-available tier, and no code held back.

## What changed, and why it is simpler

Upstream OpenWork used an open-core model: the desktop app and core platform
were MIT, while the `ee/` directory — OpenWork Den, the organization control
plane — was source-available under the "OpenWork EE License."

That split is gone here. `ee/` was deleted rather than relicensed, which means:

1. **There is nothing left to relicense.** Every file in this repository is MIT.
   No file is under a second license, and no license text needs to travel with
   a particular directory.
2. **Use it however you like.** Commercially, for any number of users, without
   a subscription, without a seat count, without an evaluation clock. There are
   no paid tiers because there is nothing to gate.
3. **The promises that mattered are now permanent.** Upstream promised that the
   MIT core would never be relicensed, that released versions would keep their
   license, and that every `ee/` release would convert to MIT after two years.
   The first of those is now moot — there is only the MIT core. The second
   still applies to *older published versions*: if you vendor a specific tag,
   read the `LICENSE` file at that tag.

See [Pricing and licensing](/start-here/pricing-and-licensing) for the licensing
terms themselves.

## What you gave up

Removing the control plane is a removal, not a trade. Some things a hosted
control plane provided simply do not exist here and have to be replaced with
your own infrastructure:

| Gone | Replace it with |
| --- | --- |
| Hosted accounts and sign-in | Nothing — the server authorizes the local client. Do not expose the port; it authorizes anything that reaches it. |
| Organizations, teams, RBAC | Your own directory, or simply don't need it |
| SSO and SCIM | An authenticating reverse proxy in front of the server |
| Managed model catalog and gateway | Point a provider `baseURL` at your own gateway |
| Desktop policy enforcement | Configuration files, or MDM |
| Audit logs | The server's own logs and data path |
